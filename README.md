## Example

To run the example project, clone the repo, and run `pod install` from the Example directory first.

## Requirements

 - iOS 13.0 or any higher version.
 - Xcode 13 or any higher version.

## Installation

### CocoaPods

StringeeWidget is available through [CocoaPods](https://cocoapods.org). To install
it, simply add the following line to your Podfile:

```ruby
pod 'StringeeWidget', '0.2.2'
```

### Swift Package Manager

Add StringeeWidget to your project with Swift Package Manager:

```text
https://github.com/stringeecom/StringeeWidget-iOS
```

Use version `0.2.2`.

Or add it to your package dependencies:

```swift
.package(url: "https://github.com/stringeecom/StringeeWidget-iOS", exact: "0.2.2")
```
